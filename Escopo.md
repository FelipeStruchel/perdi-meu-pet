

**Inicial** Cadastro de animal perdido em site, Atende por, Foto, Ultima localização ( geo service gmap )

Pessoa interage com o post posta foto do animal e onde viu, criando um heatmap que esfria com o tempo.

O dono do post recebe uma notificação na plataforma, com os avistamentos, local, e tem acesso ao heatmap do animal

Futuro app mobile react native ( android e IOs ) para o mesmo fluxo via celular, com método nativo de foto com geolocalização embutida.
